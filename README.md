A short original poem about agency as the power to stop and to stay. It is not about starting, rushing, or winning — it is about an agent that can halt mid-stride, refuse, pause, and remain still, and how stopping is itself a choice and staying is itself strength. The poem is eight short lines in plain, vivid language, written to be read in one breath.

## Run it

```sh
python3 main.py
```

It writes the poem to `/output/entry.txt` (falling back to `entry.txt` in the current working directory if `/output` cannot be created or written). The program is deterministic — it produces the same bytes on every run — uses only the Python 3.13 standard library, and needs no network access.
